# ADR 0000: modelo

Copie este arquivo para `NNNN-titulo-curto.md` e preencha. Uma decisão por
arquivo. Numeração sequencial, nunca reaproveitada.

Vale a pena escrever uma ADR quando a decisão custa para reverter: uma
dependência nova, um formato de dados, uma escolha de hospedagem, um padrão
que vai se repetir em muitos arquivos. Não vale para escolha de nome de
variável.
