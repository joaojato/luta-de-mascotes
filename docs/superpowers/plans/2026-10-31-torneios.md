# Pelada, Torneios, dificuldade clara e lutador aleatório: plano

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pelada e Torneios no menu, dificuldade numa tela própria com
extremos bem distantes, casa ? na seleção, mata-mata e pontos corridos
contra a CPU, com o torneio salvo no navegador.

**Architecture:** Regras do torneio e do salvamento em módulos puros e
testados (`src/game/torneio.ts`, `src/game/torneioSalvo.ts`), como
`cpu.ts`. Três cenas novas (`DificuldadeScene`, `TorneioScene`,
`TorneioQuadroScene`); `CharacterSelectScene` e `MatchScene` ganham o
caminho do torneio. O torneio salvo em localStorage é a única fonte do
torneio em andamento: toda cena o lê de lá.

**Tech Stack:** Phaser 4, TypeScript, Vite, Vitest. Sem dependência nova.

**Spec:** `docs/superpowers/specs/2026-10-31-torneios-design.md`

## Global Constraints

- Português sem travessão em todo texto de tela e de doc.
- Regra do JSON: elenco vem de `selecionavel`, nunca de lista de ids.
- Médio da CPU inalterado: comportamento novo só roda quando o número do
  perfil é maior que zero, sem consumir sorteio quando é zero.
- Pontos: 2x0 vale 2, 2x1 vale 1, derrota vale 0.
- Desempate: saldo de rounds, rounds ganhos, confronto direto, sorteio.
- 16 times travado com "Precisa de 16 lutadores (hoje N)" enquanto o
  elenco selecionável tiver menos de 16.
- Toda aleatoriedade passa por `aleatorio: () => number` injetável.
- `MatchScene.ts` e `BaseScene.ts` têm mudanças de outra sessão sem
  commit: commitar só os próprios trechos (`git diff` + `git apply --cached`).
- Identidade de rua (`docs/identidade-ui-v1.md`); cartão sem ilustração usa
  `createSelectionCard` só com título e subtítulo.

## Review Focus

1. Torneio salvo com lutador que saiu do elenco (JSON mudou): carregar
   devolve `null` e a tela de Torneios não oferece "Continuar".
2. Sair da luta do torneio no meio (Esc): o torneio continua salvo no
   estado de antes da luta, e "Continuar" repete essa luta.
3. Recarregar a página na tela de chaveamento ou tabela: "Continuar"
   volta exatamente à mesma rodada.
4. Casa ? com o outro cursor já parado num lutador: o sorteio nunca cai
   nele (1 VS 1 e 1 VS CPU).
5. localStorage indisponível (aba anônima que bloqueia, cota): o torneio
   roda sem salvar, sem erro.

Os testes de 1, 3 e 5 ficam na Task 4; o 4 na Task 3; o 2 é verificado no
navegador na Task 5.

### Task 4: Regras do torneio e salvamento

**Files:**
- Create: `src/game/torneio.ts`, `src/game/torneio.test.ts`, `src/game/torneioSalvo.ts`, `src/game/torneioSalvo.test.ts`

**Interfaces (Produces, usadas na Task 5):**

```ts
export type FormatoTorneio = 'mata-mata' | 'pontos-corridos'; // mover de types.ts para cá
export type Placar = [number, number]; // rounds do time a, do time b
export interface Luta { a: string; b: string; placar: Placar | null }
export interface Torneio {
  versao: 1;
  formato: FormatoTorneio;
  tamanho: 8 | 16;
  dificuldade: Dificuldade;
  jogador: string;
  times: string[];
  rodadas: Luta[][];   // mata-mata: cresce rodada a rodada; pontos corridos: todas desde o início
  rodadaAtual: number;
}
export interface LinhaTabela { time: string; pontos: number; lutas: number; vitorias: number; derrotas: number; roundsPro: number; roundsContra: number }
export type Situacao =
  | { tipo: 'em-andamento' }
  | { tipo: 'campeao' }
  | { tipo: 'eliminado'; fase: string }
  | { tipo: 'posicao'; posicao: number };

export function criarTorneio(formato: FormatoTorneio, tamanho: 8 | 16, jogador: string, elenco: string[], dificuldade: Dificuldade, aleatorio?: () => number): Torneio;
export function lutaDoJogador(t: Torneio): Luta | null;
export function registrarLutaDoJogador(t: Torneio, placarDoJogador: Placar, aleatorio?: () => number): Torneio; // novo objeto
export function pontosDaLuta(placarDoTime: Placar): number;
export function tabela(t: Torneio, aleatorio?: () => number): LinhaTabela[]; // ordenada
export function situacao(t: Torneio): Situacao;
export function nomeDaRodada(t: Torneio, rodada: number): string;
export function torneioDisponivel(tamanho: 8 | 16, elenco: number): boolean;
```

```ts
// torneioSalvo.ts
export const CHAVE_TORNEIO = 'luta-de-mascotes-torneio';
export function salvarTorneio(t: Torneio, storage?: Storage): void;     // engole erro de cota/bloqueio
export function carregarTorneio(elenco: string[], storage?: Storage): Torneio | null;
export function apagarTorneio(storage?: Storage): void;
```

Regras que o construtor não decide:
- `criarTorneio`: jogador + `tamanho - 1` sorteados do resto do elenco,
  sem repetir; lança erro se o elenco não basta.
- Mata-mata: rodada 0 = `times` embaralhados em pares adjacentes. Ao
  registrar, o jogador recebe seu placar, as outras lutas da rodada são
  sorteadas (50% cada lado, placar 2x0 ou 2x1 com 50% cada) e, se o
  jogador venceu e ainda há rodada, a próxima é montada com os vencedores
  na ordem (vencedor da luta 0 contra o da 1, 2 contra 3...).
- Pontos corridos: método do círculo, `tamanho - 1` rodadas de
  `tamanho / 2` lutas, cada par exatamente uma vez. Registrar lança o
  placar do jogador, sorteia as outras lutas da rodada e avança.
- `nomeDaRodada`: mata-mata por lutas na rodada (8 Oitavas, 4 Quartas, 2
  Semifinal, 1 Final); pontos corridos `"Rodada N de M"`.
- Desempate de `tabela`: pontos, saldo de rounds, rounds pró, confronto
  direto (só entre dois empatados), sorteio.
- `situacao`: mata-mata perdeu → eliminado com o nome da rodada; venceu a
  final → campeão; pontos corridos depois da última rodada → posição (1 é
  `campeao`).
- `carregarTorneio` devolve `null` para JSON inválido, `versao` diferente,
  ou qualquer time fora do `elenco`.

- [ ] **Step 1: testes de `torneio.test.ts`** (semente fixa como em
  `cpu.test.ts`):
  - `'cria 8 times sem repetir, com o jogador'` e `'recusa elenco pequeno'`.
  - `'pontos: 2x0 vale 2, 2x1 vale 1, derrota 0'`: `pontosDaLuta([2,0])===2`, `([2,1])===1`, `([1,2])===0`, `([0,2])===0`.
  - `'pontos corridos: 7 rodadas de 4 lutas, cada par uma vez'`.
  - `'mata-mata de 8: quartas, semi, final e campeão'` (jogador vence 3).
  - `'mata-mata: perdeu nas quartas, eliminado nas Quartas'`.
  - `'placares sorteados são 2x0 ou 2x1'`.
  - `'tabela desempata por saldo de rounds'` com torneio montado à mão.
  - `'pontos corridos: perder não elimina e no fim dá a posição'`.
  - `'16 times só com 16 no elenco'`: `torneioDisponivel(16, 10) === false`, `(16, 16) === true`, `(8, 10) === true`.
- [ ] **Step 2: testes de `torneioSalvo.test.ts`** com um `Storage` falso em
