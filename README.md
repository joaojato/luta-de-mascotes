# Luta de Mascotes

Jogo de luta 2D com mascotes de clubes de futebol do Brasil, no espírito de
Street Fighter. Trabalho da matéria CTN1423 Games, Narrativas e Comunicação
(PUC-Rio, 2026.2). Feito por vibecoding com Claude Code, Phaser 4 e
Spriterrific, a partir do [Vibe Fighter](https://github.com/chongdashu/vibe-fighter)
do Chong-U (ver `docs/decisoes/0003-base-chong-u.md`).

- Primeira sessão: `COMECE-AQUI.md`.
- Contrato do projeto (para o agente e para quem for mexer): `CLAUDE.md`.
- Design, arte, roteiro e decisões: `docs/`.

```
npm install
npm run dev      # http://localhost:5173 (com ?shell=game para esconder o painel de debug)
npm run check    # typecheck + testes + build, o portão antes de "terminei"
```
